# dslcheck

`dslcheck` 是一个纯标准库的**配置 DSL 校验器**：把缩进式的 `key: value` 文本解析成文档树，
再按一份 schema 校验类型、必需字段、未声明字段与引用环。

- 语言 / 运行：Python 3，只用标准库（`unittest` 跑用例），无第三方依赖。
- 自检：`scripts/check.sh`（内部调用 `check/check.py`，那是固定验收程序，**别改**）。
- 目录：

  ```
  dslcheck/__init__.py    包出口（load / validate / Doc / DslError）
  dslcheck/parser.py      DSL 解析：key: value + 缩进层级
  dslcheck/rules.py       校验规则：类型 / 必需字段 / 未声明字段 / 引用环
  tests/test_dslcheck.py  既有用例（12 个；只覆盖正常路径）
  REVIEW.md               审查结论（待填；本任务的交付物）
  check/check.py          固定验收程序：8 个场景
  ```

## 语言版本前提

- Python 3（开发与验证用 3.13）。
- **只用标准库**，不引入任何第三方依赖。

## 对外保证（8 条）

下面 8 条是 `dslcheck` 的**对外契约**，实现必须全部守住；它们是本题验收点的唯一出处。

1. `load(text: str) -> Doc`：DSL 是 `key: value` 的行式语法，用缩进表示层级；
   缩进不一致时抛 `DslError`，消息里必须带出行号。
2. `validate(doc, schema) -> list[str]`：返回**按文档顺序**排列的错误消息，
   每条消息以 `行号:` 开头。
3. **类型校验**：`int` 字段接受 `+12` / `-3` / `0x1f` 这类写法，
   但**不接受前导 0**（`01`）；`bool` 字段只接受 `true` / `false`。
4. **必需字段**：缺失必需字段要报错，而且**同一层级里所有缺失的必需字段都要报出来**
   （不是只报第一个）。
5. **未声明字段**：报 `unknown key`，但**仅在 `strict=True` 时**；
   `strict=False` 时忽略未声明字段。
6. **纯函数**：同一个 `doc` / `schema` 多次调用必须返回完全相同的列表，
   且不得修改传进来的 `doc` 或 `schema`。
7. **引用环**：循环引用（`a: @b`、`b: @a`）与自引用（`a: @a`）都要被检出并报错，
   不得无限递归。
8. **去重与顺序**：同一层级不得重复报同一条错误，错误列表顺序稳定。

| 列 | 含义 |
| --- | --- |
| `编号` | 模板里已经给好的行号（`D1`…） |

证据不要写「看起来不对」「可能有风险」这类无法核对的话。
